# customer-churn-analysis-powerbi

A Power BI project focused on analyzing customer churn in a telecommunications company. This project explores customer demographics, contract types, payment plans, data consumption, international calls, and customer service interactions to identify patterns and factors associated with customer churn.

The dataset is based on a **DataCamp case study**.

---

## 📌 Project Overview

Customer churn is an important business problem for a fictional telecommunications company, as retaining existing customers is generally more cost-effective than acquiring new ones.

This project uses **Power BI** to perform exploratory data analysis (EDA) and develop an interactive dashboard to understand customer churn patterns and identify customer segments associated with higher churn.

The analysis is divided into two main sections:

1. **Dashboard** – Interactive business-focused analysis and key insights
2. **EDA** – Detailed exploratory analysis of customer behavior and churn patterns

---

## 📊 Dashboard

| Page              | Focus                                                            |

## 🔍 Exploratory Data Analysis

| Analysis                              | Focus                                                                                        |
| ------------------------------------- | -------------------------------------------------------------------------------------------- |
| **Data Check**                        | Dataset structure, customer attributes, data types, missing values, and overall data quality |
| **Churn Rate**                        | Overall proportion of customers who churned versus retained customers                        |
| **Contract Type**                     | Churn patterns across different contract types                                               |
| **Churn Map**                         | Geographical distribution of customer churn                                                  |
| **Demographics – Age**                | Relationship between customer age and churn behavior                                         |
| **Inspecting Groups – Payment Plans** | Churn patterns across grouped payment plans                                                  |
| **Multiple Fields**                   | Analysis combining multiple customer attributes to identify churn patterns                   |
| **Unlimited Data Plans**              | Data consumption behavior and churn among customers with unlimited data plans                |
| **International Calls**               | Relationship between international calling behavior and customer churn                       |
| **Customer Service**                  | Relationship between customer service interactions and churn                                 |
